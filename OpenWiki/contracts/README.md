# OpenWiki/contracts — Contratos de Abstracción y Protocolos de Datos

## Propósito
Este directorio contiene los contratos formales que desacoplan las fuentes de datos del motor de visualización:

1. **`contrato_actualizacion_datos_riqueza_global.md`:** Contrato formal de actualización y compilación determinista.
2. **`story-model.js` (en `src/contracts/`):** Generador del modelo de historia canónica y diccionario i18n dual (Nominal / Valor Presente).
3. **`abstraction-contract.js` (en `src/contracts/`):** Definición de la interfaz agnóstica a proveedores.
