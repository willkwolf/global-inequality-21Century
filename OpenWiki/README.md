## Preservación de Operatividad Técnica
Los directorios de datos y scripts operativos (`OpenWiki/spec/` y `OpenWiki/scripts/`) se conservan en su ruta original para garantizar la compatibilidad 100% determinista con los comandos `npm test`, `npm run apply-spec` y `npm run validate-spec`.
