# Dominio VI: Presentación, Gramática Visual y Experiencia de Usuario

## Propósito y Alcance del Dominio
Este dominio define la gramática visual, el diseño de interacción, el recorrido de scrollytelling, el inventario de activos SVG y las directrices de diseño universal del artefacto interactivo.

Garantiza que la interfaz de usuario actúe como un **instrumento cognitivo de deducción**, donde cada color, transición, contraste y forma geométrica comunique una relación matemática y semántica real.
